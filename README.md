# ZAYX-OS — The Future of E-commerce

ZAYX-OS is a next-generation, fully decentralized Web3 e-commerce platform for selling physical and digital products online. Payments are 100% on-chain crypto, powered by smart contracts, DAO governance, and a suite of AI-powered features.

## ✨ Features

*   **Decentralized Payments:** Accept cryptocurrency payments directly through smart contracts.
*   **DAO Governance:** A community-governed platform where token holders can vote on proposals.
*   **AI-Powered:** An AI assistant to help you manage your store, and an AI-powered search for customers.
*   **3D Product Previews:** Showcase your products in 3D, giving customers a more immersive experience.
*   **NFT Receipts:** Issue NFT-based receipts for every purchase, providing a permanent, on-chain record of ownership.
*   **And much more...**

## 🚀 Getting Started

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/your-username/zayx-os.git
    ```

2.  **Install dependencies:**

    ```bash
    npm install
    ```

3.  **Set up your environment variables:**

    Copy the `.env.example` file to a new file called `.env.local` and fill in the required values.

4.  **Run the development server:**

    ```bash
    npm run dev
    ```
